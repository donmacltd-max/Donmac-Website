## C. Brand notes

* **Font**: Donmac's house font Maiandra GD is not licensed for web embedding, so the site uses Plus Jakarta Sans (as the brief specifies). The logo is used as an image, so its lettering is unchanged.
* **Logo**: the full official logo (with "SOLAR | ICT | E-MOBILITY" and "Serving You All The Way!") is used in both the header and the footer, from the 1523 px transparent PNG, served at high resolution for sharp display. For crisper rendering at every size, ask the logo designer for the original vector file (SVG, AI or EPS) and replace public/images/brand/donmac-logo-full.png; an automatic trace would alter the letterforms, so it was not attempted.
* **Colours**: primary red #990000 (logo artwork measures about #B30000), orange #FF6600, dark burgundy #450609. For WCAG AA contrast, small orange text on white uses a deeper tone (#B84A00) and orange buttons carry dark text.
